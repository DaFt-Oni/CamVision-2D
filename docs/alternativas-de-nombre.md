# Alternativas de nombre

Propuestas para el simulador académico de cobertura geométrica 2D:

| Nombre       | Enfoque                                                                 |
| ------------ | ----------------------------------------------------------------------- |
| CoberPlan    | Une cobertura y planificación; describe bien la función principal.      |
| VisorPlan    | Breve, sobrio y relacionado con la edición del plano.                   |
| GeoVisión    | Destaca el modelo geométrico y los campos de visión.                    |
| PlanoVista   | Cercano y fácil de relacionar con el espacio de trabajo.                |
| Foco2D       | Corto; comunica orientación y simulación en dos dimensiones.            |
| CampoVisual  | Directo y técnico; se relaciona con la apertura de las cámaras.         |
| CoberturaLab | Resalta el carácter académico y de experimentación.                     |
| GeoFoco      | Combina geometría y orientación.                                        |
| Visor2D      | Minimalista y descriptivo del entorno.                                  |
| Ángulo       | Destaca trigonometría y orientación; requiere un subtítulo descriptivo. |

Las opciones que mejor encajan con un estilo profesional y minimalista son **CoberPlan**, **VisorPlan** y **GeoVisión**. Son propuestas de nombre; esta revisión conserva OptiVision hasta que se elija una.
